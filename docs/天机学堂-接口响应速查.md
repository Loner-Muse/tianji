# 天机学堂 — 接口响应速查(浏览器直接看版)

> 目的:**不装 Apifox/Postman,在浏览器里直接看到接口的真实响应(JSON)**
> 网关地址统一为 `http://api.tianji.com`
> 生成日期:2026-10-10

---

## 一、准备工作:让浏览器带上登录token

大部分接口需要登录,不带 token 会返回 `{"code":401,"msg":"..."}`。**二选一**:

### 方式① 装 Chrome/Edge 插件(推荐,GET接口用这个)

1. 装插件 **ModHeader**(Chrome 应用商店 / Edge 扩展商店搜)
2. 插件里添加一个请求头:
   - Name: `authorization`
   - Value: `<你的token>`(获取方法见下方)
3. 装好后,**地址栏粘贴下面任意接口的 URL 回车,就能直接看到 JSON 响应**

### 方式② 从浏览器F12复制token(获取token最简单的方法)

1. 打开 `www.tianji.com`,用 **jack / 123** 登录
2. F12 → **Network** → 随便点一个请求 → **Headers** → 找到 `authorization` 的值,复制
3. (token有效期30天)

### 方式③ F12 Console 一键登录拿token

浏览器打开 `www.tianji.com` → F12 → **Console** → 粘贴执行:

```js
fetch('http://api.tianji.com/as/accounts/login',{
  method:'POST',headers:{'Content-Type':'application/json'},
  body:JSON.stringify({type:1,username:'jack',password:'123'})
}).then(r=>r.json()).then(d=>console.log('TOKEN =', d.data))
```

## 三、POST/PUT 接口(F12 Console 执行)

浏览器地址栏只能发 GET,**POST 接口请用 F12 Console**(打开任意天学页面按F12):

### ① 提交学习进度(视频续播上报)
```js
fetch('http://api.tianji.com/ls/learning-records',{
  method:'POST',headers:{'Content-Type':'application/json','authorization':TOKEN},
  body:JSON.stringify({sectionType:1,lessonId:2,sectionId:1,moment:150,duration:300,commitTime:'2026-10-10T18:00:00'})
}).then(r=>r.json()).then(console.log)
```
响应:`{"code":200,"msg":"OK"}`

### ② 选券方案(结算页推荐优惠)
```js
fetch('http://api.tianji.com/prs/user-coupons/available',{
  method:'POST',headers:{'Content-Type':'application/json','authorization':TOKEN},
  body:JSON.stringify([{id:7,cateId:3003,price:10000}])
}).then(r=>r.json()).then(console.log)
```
响应:
```json
{"code":200,"msg":"OK","data":[
  {"ids":["2108543790746824706"],"rules":["每满100减26，上限80"],
   "discountAmount":2600,"discountDetail":{"7":2600}}
]}
```

### ③ 点赞
```js
fetch('http://api.tianji.com/rs/likes',{
  method:'POST',headers:{'Content-Type':'application/json','authorization':TOKEN},
  body:JSON.stringify({bizId:9998,bizType:'QA',liked:true})
}).then(r=>r.json()).then(console.log)
```
响应:`{"code":200,"msg":"OK"}` ;取消点赞把 `liked` 改 false
> 注意:点赞数**约3秒**后同步到列表(定时任务)

### ④ 领取优惠券
```js
fetch('http://api.tianji.com/prs/user-coupons/1630121002899881985/receive',
  {method:'POST',headers:{'authorization':TOKEN}}).then(r=>r.json()).then(console.log)
```
响应:`{"code":200,"msg":"OK"}` ;重复领取会返回 `领取次数过多`

### ⑤ 发布问题
```js
fetch('http://api.tianji.com/ls/questions',{
  method:'POST',headers:{'Content-Type':'application/json','authorization':TOKEN},
  body:JSON.stringify({courseId:2,chapterId:1,sectionId:1,title:'浏览器测试问题',description:'测试'})
```


## 四、状态码速查(看响应先看这个)

| 你看到的 | 含义 |
|---|---|
| `"code":200` | ✅ 成功,看 data |
| `"code":400` | 业务拒绝(参数错/重复领/没库存),看 msg |
| `"code":500` | 服务端异常,需要查日志 |
| HTTP 401 | 没带token / token过期 |
| HTTP 403 | 权限不够(学员调管理端接口) |
| HTTP 404 | 路径不对 |
| HTTP 502 | 服务没起来(网关转发失败) |
| 打不开(连接失败) | 虚拟机没开 / 服务挂了 |
