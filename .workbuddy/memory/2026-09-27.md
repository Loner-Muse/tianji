**★ 实测 hutool `BeanUtil.mapToBean`（hutool-all 5.8.36，用 javac/java 直接跑验证）**：

- 签名只有 3 参/4 参，**没有 2 参**：
  - `mapToBean(Map<?,?>, Class<T>, boolean isIgnoreError)`
  - `mapToBean(Map<?,?>, Class<T>, CopyOptions)`
  - `mapToBean(Map<?,?>, Class<T>, boolean, CopyOptions)`
- ✅ **类型自动转换完全可用**：`String "100"` → `Integer 100`；`String "1790515129770"`（毫秒戳）→ `LocalDateTime`，无需手动 set

- `tj-common` 的 `BeanUtils extends cn.hutool.core.bean.BeanUtil` → hutool 全部静态方法都继承来，可直接 `BeanUtils.mapToBean(...)`

## day11 发放时间为 null 的兜底（已实现，BUILD SUCCESS）

**问题链**：`Coupon.issueBeginTime` / `issueEndTime` 允许为 null（只配一侧是合法配置）→ `cacheCouponInfo` 里 `String.valueOf(DateUtils.toEpochMilli(null))` 存成字符串 `"null"` → `mapToBean(..., false)` 拿 `"null"` 转 `LocalDateTime` **抛异常 → 领券接口 500**。

**两处兜底（已写）**：
